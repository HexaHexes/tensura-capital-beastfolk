# Tensura Capital: Beastfolk

The Beastfolk faction capital - the Great Lodge in the plains and savannas -
for use with the Tensura Faction Spawn ecosystem.

## What it does

Registers the Beastfolk capital. Once registered, the spawn mod picks it up
automatically: a player who first picks (or reincarnates into) one of the
Beastfolk races is placed at the nearest registered capital to the world
spawn, and may return to it at will.

- **Beastfolk** - earthen lodges of mud bricks and terracotta with oak
  timber, hay stores and copper accents, raised around a fire circle
  (generates in the plains, savannas and open forests).

Install like any mod, alongside Tensura Faction Spawn.

## Dependencies

| | Mod | Why |
|---|---|---|
| Required | Minecraft | - |
| Required | NeoForge | - |
| Required | Tensura Faction Spawn | Owns the central capital tags and arrival behaviour |
| Required | Tensura: Reincarnated | Owns the Beastfolk races the capital serves |
